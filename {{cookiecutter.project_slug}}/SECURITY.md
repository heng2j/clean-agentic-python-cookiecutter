# Security policy

Do not open a public issue containing a credential, private dataset, exploitable
detail, or sensitive result. Contact the maintainers through the private security
reporting channel configured on the repository. If none is configured, stop and
ask a maintainer for a private channel; do not guess an address.

State the affected version or commit, impact, minimal reproduction, and any known
workaround without including unrelated sensitive material. Support windows and
response times are not promised by this starter; adopters must publish their own.

If a key may have entered Git, logs, notebooks, artifacts, or an agent trace,
revoke or rotate it first. Deleting the visible string is not sufficient because
history and caches may retain it.
