# Results

Generated runs are ignored here by default. This prevents large, private, stale,
or misleading outputs from drifting into the repository.

A maintainer may deliberately add a small reference result only after reviewing
its license, privacy, size, scientific meaning, and provenance. Record the source
commit and dirty state, argv/configuration, input and lock hashes, Python/platform,
random seeds, material hardware/backend settings, output hashes, validation
oracle, and limitations. A manifest can make a run traceable; it cannot prove
that the command ran as claimed or that the result is scientifically valid.
