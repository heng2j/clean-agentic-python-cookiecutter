# Curated reference results

This directory is the narrow exception to the default ignored-results policy.
Add only small, reviewable reference outputs with an accompanying provenance
manifest and a deterministic verification command. Maintainers must explicitly
review size, privacy, licensing, scientific meaning, and whether Git is the
appropriate storage system.

Internal hashes and metadata make an artifact traceable within the repository;
they do not prove the recorded command ran or that the scientific conclusion is
valid.
